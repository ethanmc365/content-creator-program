Written 31 Aug 2026, at the end of a long session. This is the working list for
whoever picks it up next, me included. Everything under "Done" is on `main` and
deployed; everything under "Open" is not started unless it says otherwise.

Read this with `docs/` and the memory files, not instead of them.

## Done and deployed

### The cutover
- The network is the app. `NetworkRoute` and `CommunityContext` no longer gate
  on the preview flag; every creator is on the worldwide shell.
- Nav is five tabs: **Worldwide** (globe), Challenges, Rooms, DMs, Calendar.
  `/home` and `/chat/:channel` redirect rather than 404.
- Header wordmark is "Content Creator Community".
- DMs and Calendar left the avatar menu (they are primary tabs).

### Security
- **Migration 149 closed a real hole.** `messages` had one SELECT policy,
  `is_member()`, which only means "are you an active profile" - so every creator
  could read every channel, including the Worldwide staff room and every market
  they are not in. Verified fixed against a plain UK creator: staff 0, Spain 0,
  Worldwide 157, UK 7. Nothing had leaked; the staff room was empty.
- 30 legacy rows were backfilled with `community_id`/`channel_id` first, so the
  policy needs no "or null" escape hatch.

### Rooms
- **Posting works again.** An `isLiveWorldwide` guard from the preview era made
  Worldwide's General, Announcements and Content tips read-only. Removed.
- Own messages are right-aligned orange bubbles; everybody else's are left. The
  "my message looks like someone else sent it" report was this: it was a flat
  Slack-style log where every row was drawn identically.
- Reply, delete (own, or any as admin - migration 147), edit, report, reactions.
- **Headings are 20/17/15 against a 14px body.** They were 16/14/14, so an H2
  was the same size as a paragraph. Renderer and composer both changed.
- Content tips room added to every market (migration 148), and `create_market`
  updated so new markets get one.
- Market scope disclaimers removed from four surfaces.
- Rooms index is drag-reorderable on mobile, sharing `rooms-market-order` with
  the desktop sidebar.

### Fixed bugs
- **UK market overview loaded nothing.** `standings.filter(s => !s.profiles.is_test)`
  - `views_leaderboard` returns flat columns, so there is no `profiles` object.
  It threw, `load()` rejected, `setLoading(false)` never ran. Only the UK showed
  it because every other market returns zero rows today. `load()` now has a catch.
- **Challenge archive view counts.** `results.final_views` is a snapshot taken
  when an admin saves results; views keep syncing off each entry's link forever
  after. One creator had drifted ~20k. The archive reads live views now and totals
  every entry, not just the ranked ones. **Ranks untouched** - that challenge is
  `best_video`, so the order is a human decision that was paid out.
- Countries appeared twice on Edit profile (WorldMap drew its own chip list).
- Adding/deleting a photo did not update the board (`lib/photoEvents`).

### Profile
Header (role beside name, age below, bigger photo), coloured named social links,
LinkedIn column (migration 146), Languages rename, bucket icon, borderless trip
rows, orange local-time icon, no Team-only card, no country list under the map,
no share card, "headed next" reads upcoming flights too, bucket list expands,
Milestones rename, flight log in the rail, travel games shows streaks off a new
pure RPC (migration 145 - `my_game_streak` WRITES and must never be called to
draw a profile), showcase sorted by views with dates past three days.

### Edit profile
Tab deep-links (`?tab=photos`), no tab hints, growing About and quote boxes,
searchable language picker, removable country chips, dial-code menu fixed,
save bar cleaned up.

## Things worth not relearning

- **`my_game_streak` WRITES.** It spends freezes. Never call it to draw a
  profile. `profile_game_stats` (145) is the pure read.
- **`results.final_views` is a snapshot and drifts.** Any surface showing views
  should read `submissions.logged_views`.
- **`is_member()` is not membership.** It means "active profile". Check
  `my_scopes()` for anything community-scoped.
- **Never retype a live function body.** `pg_get_functiondef` first. Migration
  148 copied `create_market` verbatim and edited four places.
- **Both revokes.** A definer function needs `revoke from public` AND
  `revoke from anon`; a safe one reads back as postgres/authenticated/service_role.
- **Drag listeners belong on pointerdown, not in an effect** keyed on drag
  state - an effect's listeners are not live until React commits, so the first
  move and sometimes the pointerup are lost. This bit the photo board and the
  boarding-pass camera.
- **The local Turnstile CAPTCHA currently hangs**, which blocks signed-in local
  testing. Worth fixing before the next session.
- QA logins are in the memory file; they are the sanctioned testing exception.
